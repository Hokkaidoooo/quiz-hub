## 使用与记录保存

打开网址后选择题库即可开始，首次访问没有预置做题记录。进度、错题和笔记自动保存在当前浏览器的本地存储中；刷新网页、正常关闭浏览器后重新打开同一网址会恢复记录。

不同电脑、浏览器和浏览器配置文件分别保存，没有账号或自动云同步。请用常规窗口学习：隐私窗口关闭后通常会清除记录，手动清理站点数据也会删除进度。中值定理题库支持导出进度和导入备份。

键盘 A–E 或 1–5 作答，N / → 下一题，P / ← 上一题，Esc 关闭 AI 面板。

## AI 讲解

在题目页的「AI 讲解 → 设置」填写自己的服务商地址、API Key 和模型。未配置 AI 时可以正常刷题。网页直接向你选择的服务商发送请求，服务商需要允许浏览器跨域调用（CORS）；密钥不会进入刷题进度或 GitHub 仓库。

勾选「记在这台电脑」后，密钥存入本机浏览器；关闭后仅在当前会话保留。AI 配置与对话各自保存在本机。

## 离线使用与部署

下载整个仓库后打开 index.html，可离线刷题和查看公式、配图。在线网址与本地文件使用不同的浏览器存储，进度分别保存。AI 讲解需要能访问对应服务商。

部署到 GitHub Pages 时，选择 main 分支和根目录 /。题库、图片、公式与 Markdown 组件均已包含在仓库内。

题库注册表为 banks.js，题库文件为 banks/<题库ID>/questions.js。维护时保留题库ID、题目ID与 storageKey，可继续使用已有学习记录。第三方组件许可证保存在 vendor 目录。
